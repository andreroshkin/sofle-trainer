# Split Keyboard Trainer

Тренажёр печати для Sofle 66 на Vue 3, TypeScript, Vite и Pinia. В интерфейсе видны обе половины клавиатуры, следующая клавиша, прогресс, скорость и точность. Можно тренировать русский и английский текст или отдельные символы.

## Запуск

Нужен Node.js 20.19+ в ветке 20 или Node.js 22.12+.

```sh
npm ci
npm run dev
```

Открой адрес, который напечатает Vite. Для проверки сборки используй `npm run build`, для её просмотра — `npm run preview`.

## Тренировка

1. Выбери **Текст** или **Символы**, затем **RU** или **EN**. Для подсказок используются стандартная ЙЦУКЕН и US. Переключи системную раскладку на тот же язык.
2. Начни печатать. Ошибка учитывается в точности, курсор остаётся на текущем символе. Скорость считается из числа правильно набранных символов по стандарту пяти символов на слово, со второй секунды замера. Таймер начинается с первого ввода и останавливается при завершении.
3. В режиме **Авто** схема показывает слой следующей клавиши. Кнопки **0–7** позволяют просмотреть слои рабочей базы вручную. В мобильной версии есть поле для экранной клавиатуры.

| Комбинация на Sofle 66 | Символ |
| --- | --- |
| Fn + Esc | `ё` в RU, обратная кавычка в EN |
| Fn + Backspace | `-`, с Shift — `_` |
| Fn + Delete | `=`, с Shift — `+` |

Браузер получает символ от системной раскладки. Аппаратная Fn может обрабатываться целиком в прошивке. Тренажёр показывает доступные клавиши `MO(n)` и Shift, когда они нужны, а переключатель слоёв управляет экранной схемой. Подсветка введённой клавиши использует `KeyboardEvent.code`, поэтому у одинаковых назначений физическое положение может быть неоднозначно.

## Импорт Vial

**Импорт .vil** открывает локальный экспорт версии 1 размером до 1 МБ. Файл проверяется в браузере и сохраняется в `localStorage` для текущего адреса. При ошибке остаётся последняя открытая раскладка. Кнопка **Вернуть базу** удаляет сохранённую пользовательскую раскладку и открывает встроенную.

Встроенный [base.vil](src/assets/base.vil) — побайтовая копия [рабочей конфигурации из PR #52](https://github.com/andreroshkin/andreroshkin-notes-vault/pull/52), blob `c243ba500e3c76d4d01b6e2e4c63bdd9848eeb34`. В экспорте восемь слоёв и 64 занятые позиции в матрице 5 × 16. `original.vil` в исходном репозитории служит резервной копией.

Профиль Sofle 66 сверяет размеры матрицы и маску ячеек `-1` каждого слоя. Экспорт с другой маской отклоняется с пояснением. Файл .vil хранит назначения по матрице, а координаты и форма клавиатуры заданы отдельным схематическим профилем в [geometry.ts](src/domain/geometry.ts). Для другой модели нужен проверенный профиль с её физическими позициями.

- `KC_TRNS` обозначен как ▽. При предпросмотре выбранный слой накладывается на слой 0, у прозрачной клавиши видно базовое назначение.
- `KC_NO` обозначен как — и блокирует базовое назначение на этой позиции.
- Подсказки поддерживают базовые QMK-коды и их распространённые алиасы, базовые числовые HID-коды, Shift-коды и простые tap-назначения `LT` и mod-tap. Неизвестные коды остаются видимыми как подписи. В MVP предпросмотр моделирует один выбранный слой поверх базового, а макросы, Tap Dance, энкодеры и комбинации активных слоёв остаются в ведении прошивки.

## Проверки

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Если установлен Google Chrome, можно запустить браузерные проверки через `PLAYWRIGHT_CHANNEL=chrome npm run test:e2e`. Они проверяют русский и английский ввод, подсказки Fn, метрики, импорт реального файла, сохранение при перезагрузке, ошибки, просмотр слоёв и узкий экран. События русской раскладки моделируются в браузере.
